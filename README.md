# TP de OCaml

Ce répertoire est consacré à de petits codes en OCaml qui est un langage informatique fonctionnel développé par l'inria.
Grâce notamment à son filtrage par motifs, OCaml offre certains avantages sur les structures de données, des types hiérarchisé et récursifs.

Dans les différents TP, j’ai exploré les spécificités du langage OCaml en manipulant les structures d'arbres (arbre binaire de recherche principalement), de pile, de queue, de dictionnaire..., mais aussi ses aspects en termes de manipulation de fonction.

Une partie de ces TP ont été fait lors de mes années en classe préparatoire, mais ont été retravaillé par la suite.
